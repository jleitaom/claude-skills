# Learning

Skills for learning a new topic. Both are manual-only (you call them) and use the
same topic folder format (in the current folder, `~/learning/<topic>/`, or both),
so you can start with theory and add projects to the same topic later.

- **[teach-it](./teach-it/)**: Learn a topic in theory: a guide in parts, with interactive figures, diagrams, charts, real-world case studies and quizzes. No projects.
- **[teach-it-with-projects](./teach-it-with-projects/)**: Learn a topic by building: essentials guide, projects from simple to real-world, interactive lab page, quizzes.
